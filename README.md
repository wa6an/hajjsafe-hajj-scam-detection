# HajjSafe – AI-Powered Hajj Scam Detection

## Project Overview
HajjSafe is an AI-powered project designed to help identify potential scams related to Hajj and help users assess suspicious information.

## Problem Statement
Pilgrims may encounter misleading information or suspicious offers related to Hajj services. Identifying potentially fraudulent content can help users make more informed decisions and improve awareness of online scams.

## Project Objectives
- Explore the use of Artificial Intelligence for Hajj-related scam detection.
- Help users assess potentially suspicious information.
- Support awareness of online safety during the Hajj season.

## Methodology
The project explores an AI-based approach to Hajj-related scam detection. The specific models, tools, and evaluation methods are documented in the project notebook.

## Project Notebook
The main Jupyter Notebook for this project is available in this repository:

`HajjSafe_Capstone_Project (5).ipynb`

## Technologies
- Python
- Jupyter Notebook
- Artificial Intelligence and Machine Learning

## Disclaimer
HajjSafe is an academic project. Its predictions should not be treated as definitive proof of fraud. Suspicious information should be verified through official sources.
## Installation and Usage

### 1. Clone the Repository

```bash
git clone https://github.com/wa6an/hajjsafe-hajj-scam-detection.git
cd hajjsafe-hajj-scam-detection
```

### 2. Install Dependencies

```bash
pip install -r requirements.txt
```

### 3. Run the Project

Open the Jupyter Notebook files in Jupyter Notebook or Google Colab and run the cells in order.
